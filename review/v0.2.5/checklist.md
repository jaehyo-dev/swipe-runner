## ART_BIBLE.md 2-4 공중 비율
- 공중에 있는 동안 키/폭 1.0 이상: 됨. 자동 테스트(tests/test_runner.gd `test_공중에서는_화면_키가_폭_이상이고_...`)가 실제 main 장면 카메라로 공중 모든 프레임을 확인
- 뜬 직후·내려올 때 약 1.2~1.3: 됨(1.22 / 1.26, 자동 테스트)
- 꼭대기에서도 1.0 아래로 내려가지 않음: 됨(1.09, 꼭대기 앞뒤로 1.08~1.10)
- 넓적해 보이는 건 착지 순간뿐: 됨(착지 순간 0.87, 그 뒤 출렁임)
- 부피 느낌: 그대로. 세로 늘어남 s에 옆 폭 1/√s
- 꼭대기 작은 출렁임: 유지(킥 2→1로 줄여 꼭대기 값이 1.10→1.08로 살짝 출렁)
- 착지 순간 툭 튀지 않음: 모양은 스프링 하나로 이어서 움직임(값이 끊기지 않음). 키/폭 1.26 → 착지 첫 프레임 1.00 → 0.87 → 최저 0.78로 v0.2.4(1.03 → 0.83 → 0.76)와 같은 빠르기로 눌림. 착지 납작함(키 배율 0.65~0.78)·착지 직후 재점프 자동 테스트 그대로 통과

## 굴절 선 색
- 증상: 몸 옆 길 선 색상 약 163°(초록). 몸 가운데는 183°(하늘빛 민트)
- 원인 찾기(같은 꼭대기 프레임): 물들이는 색을 끄면(흰색) 선이 하늘색으로 돌아오지만 몸이 보라·회색으로 탁해짐 / 굴절 세기를 0으로 하면 선이 곧게 펴질 뿐 초록은 그대로 → 원인은 **비친 화면을 물들이는 색 `transmit_tint` (0.18, 1.0, 0.58)**. 하늘색 길 선(G≈B)에 곱하면 파랑이 0.58배로 빠져 초록이 됨. 굴절 세기·가장자리 처리는 원인 아님
- 고침: 어두운 보라 배경은 지금처럼 물들이고, 밝은 곳(max(G,B)이 0.35~0.8 사이에서 부드럽게 넘어감)은 밝기만 살려 `line_tint` (0.6, 1.0, 1.0) 하늘빛 민트로 칠함. 고친 뒤 몸 영역에서 초록 픽셀(G−B > 25) 287개 → 0개
- 착지 직전 몸 꼭대기의 밝은 부분은 몸 뒤 가로 길 선이 굴절된 것(렌즈 효과, 하늘빛 민트)

## 바꾸지 않은 것
- 판정(점프 0.6초·1.6, 슬라이드, 충돌 범위), 색 팔레트, 기본 크기(폭 1.0·키 0.8), 공중 둥근 바닥(flat_bottom), 그림자, 스와이프 한 번 = 한 동작: 기존 자동 테스트 그대로 통과
