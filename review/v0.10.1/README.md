## 바뀐 다른 것
- 오늘의 판 배치: 고비 뒤 압박이 오르며 같은 날짜도 v0.10.0과 다르다. 고정 지문 #1 `99e7039b5e52de92` → `900b07ea24aa43e3`, 날짜 30개 `hash_mac.txt` ALL `6a72cd95a1a0faf1`. 배포하는 날(#1)은 v0.10.0 판과 v0.10.1 판이 섞인다 (캐시)
- 도전 모델: 강해진 모델에서 중앙값이 안전 모델보다 낮아졌다(약 6200 vs 7300, 고비 전 사망이 많음). 대신 10000점 이상이 더 자주 나온다(10% vs 4%). 테스트를 "중앙값이 더 높다" → "10000점 이상이 더 많다"로 바꿨다
- 시간 기준 테스트(보통 중앙값 25~40초, 잘함 50~80초)를 점수 목표 테스트로 바꿨다

## 미확인
- 고비 신호(0.4초 빛)는 계산(StageLight.wall_flash, wall_age) 자동 테스트만. 화면은 기존 단계 빛남과 같은 재질 값이라 캡처하지 않았다 (66초를 버텨야 보임). 휴대폰에서 직접 볼 것
- 사람 모델은 추정치다. 사용자 실제 점수 기록이 오면 `MODELS` 환경 변수로 모델을 맞춘 뒤 다시 맞춘다
