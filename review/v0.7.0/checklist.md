## QUALITY_BAR
### 읽기
- [ ] 처음 하는 사람이 3번 안에 동작을 알아챔: 미확인(사람)
- [x] 모양만으로 구분: 장애물 모양·색은 그대로
- [x] 안개에서 나타난 뒤 반응 시간 0.6초 이상: 보이는 시간 최소 0.75초, 알아볼 수 있는 시간(반쯤 진해진 때) 0.675초
- [ ] 주인공이 가장 밝고 시선이 떨어지지 않음: 밝기 값은 그대로(자동 테스트). 160 뒤 길어지는 빛 줄기가 시선을 끄는지는 미확인(사람)
- [x] 거리 숫자가 장애물·주인공을 가리지 않음 (`phone_run.png`)

### 조작감·손맛
- 입력·모션·소리 코드는 바뀌지 않았다. 자동 테스트 전부 통과

### 공정함
- [x] 억울한 충돌 0: 판정 크기는 그대로. 구간 판정은 판정 폭을 통째로 건너뛴 경우에만 쓴다 (`sweep.md`)
- [x] 피할 수 없는 조합 없음: 보이는 줄만 보는 완벽한 자동 플레이어(입력 간격 0.22초) 처음부터 10분 × 시드 5개 충돌 0. 줄 읽기는 열린 줄을 알아볼 수 있을 때만 낸다
- [x] 같은 시드 같은 배치 (자동 테스트)

### 흐름
- [x] 부딪힘 → 다시 달리기 1.5초 이내 (자동 테스트)
- [x] 재시작 때 검은 화면 없음. 새 장애물은 약 0.4초 뒤 안개에서 나온다 (`phone_restart.png`)
- [ ] 한 판 30초~2분: 모델은 31.3초, 74.5초. 사람은 미확인. 이번 목표는 "하루 종일 안 죽는다"를 없애는 것이고 모델은 모두 3분 안에 죽는다

## 플레이해 봐야 아는 것
- 보이는 시간 0.75초, 속도 50 이상에서 "공정하지만 빡빡한" 느낌인지, 그냥 안 보여서 죽는 느낌인지
- 사람 모델의 "속도가 빠를수록 알아보는 데 오래 걸린다" 가정이 실제와 맞는지 (잘하는 모델이 70~82초에 몰려 죽는다)
- 숨 고르기 마디가 숨 고르기로 느껴지는지
- 안개가 가까워져 길이 짧아 보이는 것이 답답하지 않은지
