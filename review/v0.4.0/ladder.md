# 처음부터 130BPM 두 바퀴까지 자동 플레이 (웹)

재현: `build_measure.sh` + `measure_ladder.mjs` (주소 `?mode=accuracy&secs=268`). 크로미움, Metal GPU, 390x844. **`--disable-audio-output`을 썼다**: 이 맥의 헤드리스 크로미움은 실제 오디오 장치에서 게임 없는 빈 페이지의 AudioContext도 0.01초에 멈췄다. 이 옵션은 같은 Web Audio 렌더러를 타이머로 돌린다. 실제 스피커 출력은 재지 못했다.

충돌 0, fps 60.0, 음악 시간 268.0초, 오디오 시계 멈춤 0회, 콘솔 오류 0, 표본 속도 48000Hz (44.1kHz 곡을 엔진이 리샘플)
