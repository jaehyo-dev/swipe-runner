# v0.10.0 품질 기준 자체 채점

QUALITY_BAR.md 기준. **통과 판정은 사용자가 휴대폰으로 플레이하고 "A급"이라고 할 때다.** 숫자·캡처는 `README.md`.

| 항목 | 결과 |
|---|---|
| 첫 화면에서 탭 한 번이면 바로 시작 | 일반 모드 그대로. 오늘의 판은 DAILY 버튼 → 스와이프 (버튼 누름은 시작이 아님) |
| 재시작·부딪힘 → 다시 달리기 1.5초 이내 | 그대로 (오늘의 판도 같은 재시작, SHARE 누름은 재시작이 아님) |
| 브라우저 콘솔 오류 0 | 0 (휴대폰·PC, 메인·오늘의 판·게임 오버·SHARE·집, ?dailyhash) |
| 390x844·1280x720 화면 잘림 없음 | 잘림 없음. PC는 SWIPE TO START가 DAILY 버튼 자리만큼 올라가 젤리 반사 아래 끝에 가까움 |
| 과하지 않다 | 새 글자는 기존 BEST 줄 크기·흰색 70%, 테·점만 연보라 |
| 글꼴·텍스처·팔레트 | Poppins ExtraLight 하나, 영어·숫자만, 테·점은 선/도형으로 그림 |

미확인: 윈도우(WSL) 지문, 휴대폰 공유 창(Web Share), 실제 휴대폰 터치로 DAILY 버튼 누르기.
