## QUALITY_BAR
### 읽기
- [ ] 처음 하는 사람이 3번 안에 동작을 알아챔: 미확인(사람)
- [x] 모양만으로 구분: 턱·막대·기둥 모양 그대로. 벽은 넓은 기둥으로 읽힘 (`wall_sheet.png`). 흑백·적록색약 시트는 이번에 다시 찍지 않음(모양과 색 값이 그대로)
- [x] 반응 시간 0.6초 이상: 160BPM 생성부터 2.58초, 또렷해진 뒤부터 1.82초
- [ ] 주인공이 가장 밝고 시선이 떨어지지 않음: HDR 값은 자동 테스트 통과. 늘어난 빛 줄기가 시선을 끄는지는 미확인(사람)
- [x] 거리 숫자가 장애물·주인공을 가리지 않음

### 조작감·손맛·공정함·흐름
- 입력, 모션, 소리, 재시작 코드는 바뀌지 않았다. 자동 테스트 전부 통과
- [x] 충돌 범위 그대로: 벽의 바깥 끝 = 기둥 둘의 바깥 끝 (자동 테스트)
- [x] 피할 수 없는 조합 없음: 자동 플레이어 시드 5개 × 160BPM 4분 충돌 0
- [x] 같은 시드 같은 배치 (자동 테스트)
- [ ] 한 판 30초~2분: 모델은 37.5초, 76.3초. 처음 하는 사람은 미확인

### 성능·기술
- [ ] 아이폰 Safari 60fps: 미확인. 120Hz도 미확인(프레임당 이동량은 `timing.md`)
- [x] 콘솔 오류 0: 게임 빌드 PC·휴대폰 (`check_web.mjs`)
- [x] 390x844, 1280x720 화면이 잘리지 않음: `phone_*.png`, `pc_*.png`

### 아트 바이블

- [x] 팔레트 밖의 색 없음, 텍스처 없음, 글꼴 하나

## 플레이해 봐야 아는 것
- 33 속도와 68° 시야각에서 멀미가 나거나 너무 빠르지 않은가
- 반 박 대시가 박 느낌을 흐리지 않는가 (박 신호는 전체 밝아짐으로 유지)
- 사람 모델은 속도만으로는 거의 어려워지지 않으므로, "쉽다"는 느낌이 줄었는지는 직접 판단이 필요하다
