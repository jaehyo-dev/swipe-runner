# 난이도 표 (v0.6.3)

`godot --headless --path . -s tools/difficulty_report.gd`, 사람 모델 두 종류, 시드 50씩.

| 목표 | 결과 | 판정 |
|---|---|---|
| 보통 모델 중앙값 30~50초 | 37.5초 | 통과 |
| 잘하는 모델 중앙값 70~110초 | 76.3초 | 통과 |
| 잘하는 모델 95%가 240초 이하 | 147.0초 | 통과 |
| 사망이 한 BPM에 40% 이하 | 보통 22% (120BPM), 잘하는 36% (160BPM) | 통과 |
| 완벽한 자동 플레이어 시드 5개 × 160BPM 4분 충돌 0 | 충돌 0, 최소 입력 간격 0.28초 | 통과 |

| 0.016 | 38.5초 | 81.6초 | 148.9초 | 42% (불통과) | 0 |

## 모델의 한계
모델은 "줄이 몇 초 뒤에 도착하는가"로 반응한다. 박 간격은 BPM이 정하므로 속도표를 올려도 모델에게는 판정 시간 창이 좁아지는 만큼만 어려워진다. 눈으로 느끼는 빠르기와 멀리서 보이는 양은 모델에 들어 있지 않아, 실제 체감은 사람이 플레이해 봐야 안다.
