# 난이도 표 (v0.5.1)

재현: `godot --headless --path . -s tools/difficulty_report.gd`. 사람 모델은 흉내일 뿐이고 실제 사람의 판단은 플레이로 확인해야 한다.

| 목표 | 결과 |
|---|---|
| 보통 모델 중앙값 35~60초 | 41.0초 통과 |
| 잘하는 모델 중앙값 90~150초 | 105.0초 통과 |
| 잘하는 모델 95%가 300초 이하 | 169.1초 통과 |
| 보통 모델: 한 BPM에 40% 이하 | 22% 통과 |
| 잘하는 모델: 한 BPM에 40% 이하 | **160BPM에 56%, 미달** |
| 기둥 45% 이하 | 43.7% 통과 |
| 완벽한 자동 플레이어 시드 5개 × 160BPM 4분 충돌 0 | 통과 |

**미달 이유:** 160BPM에 92초에 도착하므로, 중앙값이 90초 이상이면 절반쯤은 160BPM에서 죽는다. 두 목표는 함께 지킬 수 없어 중앙값을 지켰다. 160BPM 안에서는 4마디마다 밀도가 오르므로, 밀도 칸을 한 칸으로 치면 가장 많이 몰린 곳은 18%다.

조절한 값: 기둥 줄을 줄이고 턱·막대를 늘림(`BIG`, `DOUBLE`), 줄 읽기 `READ_SHALLOW` 0.012·0.03, `READ_DEEP` 0.011 (130BPM부터), 밀도 칸마다 0.003. 속도표는 지시문 그대로다.
