# v0.2.8 화면 확인 기록

- 방법: Godot 데스크톱(Compatibility)에서 `--fixed-fps 60 --resolution 720x1280`, seed 136으로 프레임을 찍어 GIF로 만듦. 웹 빌드는 로컬 서버로 열어 헤드리스 크롬(swiftshader)에서 PC 1280x720(방향키), 휴대폰 390x844(터치)로 확인
- GIF: `hit_block`·`hit_hurdle`·`hit_bar`·`fast_drop`은 0.5배(원본 50fps → 25fps), `restart`는 실제 속도(25fps). 모두 3MB 이하
- 그 밖의 파일: `phone_run.png`, `phone_gameover.png`(390x844), `sounds/`(소리 후보)

## 공중 아래 스와이프 판정 (억울한 충돌 방지)
| 대상 | 판정 | 이유 |
|---|---|---|
| 막대 | 입력한 순간부터 지나감, 착지 프레임부터 바로 낮은 판정 | 슬라이드하겠다는 입력이 받아들여졌는데 떨어지는 0.15초 때문에 죽으면 억울함 |
| 허들 (입력 순간 이미 넘고 있음) | 부딪히지 않음 | 넘고 있었는데 내려오다 닿아 죽으면 억울함 |
| 허들 (아직 앞에 있음) | 높이가 0.45 아래면 부딪힘, 슬라이드로도 못 지남 | 눈에 보이는 대로, 보통 규칙과 같음 |
| 블록 | 그대로 부딪힘 | 레인을 바꿔야 피하는 장애물 |
