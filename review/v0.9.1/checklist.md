# v0.9.1 품질 기준 자체 채점

QUALITY_BAR.md 기준. **통과 판정은 사용자가 휴대폰으로 플레이하고 "A급"이라고 할 때다.** 아래는 자체 채점이고, 확인 못 한 것은 미확인으로 적었다. 측정 숫자는 `README.md`.

| 항목 (QUALITY_BAR) | 결과 |
|---|---|
| 첫 화면에서 탭 한 번이면 바로 시작 | 그대로. 메인 화면이 뜨자마자 누르면 장애물 셰이더 준비를 마저 하느라 최대 약 1.9초 뒤 시작(GPU 측정). 이 사이 화면 변화는 없다 |
| 재시작 때 검은 화면·깜빡임·멈칫 없음 / 첫 판 끊김 | 첫 판 12초 33ms 넘는 프레임 0 (GPU 60Hz) |
| 부딪힘 → 다시 달리기 1.5초 이내 | 그대로 (일시정지 버튼은 게임 오버에서 숨김) |
| 효과음이 BGM 박자에 얹힘 | 일시정지 뒤 박자 평균 어긋남이 일시정지 없을 때와 1ms 안. 이어 한 직후 몇 프레임만 최대 약 40ms |
| 첫 로딩 10초 이내(일반 LTE/와이파이) | 와이파이 20Mbps 8.0~8.6초 통과, Fast 4G 14.7~15.4초 미달(엔진 wasm 9.9MB). 로딩 화면은 0.5초 안에 보여 고장으로 보이지 않음 |
| 브라우저 콘솔 오류 0 | 0 (휴대폰·PC·짧은 창, 설정·새로고침·일시정지·자동 일시정지) |
| 390x844·1280x720 화면 잘림 없음 | 메인·설정·일시정지 화면 잘림 없음. 짧은 창 800x900도 확인. 아이폰 안전 영역 미확인 |
| 과하지 않다 | 진동은 충돌·PERFECT·새 기록만, 설정에서 끔. 실제 느낌 미확인(안드로이드) |
| 글꼴은 Poppins ExtraLight 하나, 텍스처 없음, 팔레트 | 새 화면 모두 Poppins ExtraLight + 연보라 #C9B8FF, 아이콘(‖·톱니)·슬라이더는 선으로 그림. 로딩 화면도 같은 글꼴 조각과 같은 색 |

미확인: 실제 휴대폰(안드로이드 진동, 아이폰 사파리 일시정지·소리 재개), 사람이 느끼는 3·2·1 박자감, 실제 4G에서의 로딩.
