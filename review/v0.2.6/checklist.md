## 장면별 화면 키/폭
화면 키/폭 = 몸 표면 점(바닥 둥글기·위아래 시차까지 반영)을 실제 게임 카메라(720x1280)로 투영한 테두리 상자의 키 ÷ 폭 (`Runner.screen_aspect`). 카메라가 위에서 약 31° 내려다보므로 팬케이크도 윗면이 보여 0.58로 잡힌다(옆에서 본 키 배율은 0.26). 땅 위 기본 모양은 약 1.02~1.05.

## ART_BIBLE.md 2-5 원칙별 결과
1. 늘어남은 속도에 비례: 됨. 목표 늘어남 = AIR_ROUND 0.1 + AIR_SPEED_STRETCH 0.37 x |위아래 속도| / 뛰는 속도. 꼭대기에서 1.06까지 동그랗게, 납작해지지 않음(꼭대기 킥 없앰). 공중 모든 프레임 1.0 이상(자동 테스트), 꼭대기를 지나면 떨어지는 동안 계속 길어짐(자동 테스트)
2. 착지는 단계적으로 깊게: 됨. 닿는 순간 아래로 킥 → 0.12초 동안 임계 감쇠 스프링으로 팬케이크(키 0.26배, 넘치지 않음) → 튕김 스프링(세기 1000, 감쇠 30)으로 종 모양 반구 → 위로 한 번(1.12), 아래로 한 번(0.98) 출렁 → 약 0.42초에 원래 모양. 팬케이크 테두리는 셰이더 rim_wave(폭 5%, 7갈래)로 일렁임
3. 보조 동작(물방울): 됨. 같은 jelly 셰이더를 쓴 작은 구 메시 3개(반지름 0.07, 12x6 분할)가 팬케이크 테두리에서 왼쪽·앞·오른쪽으로 튀어(높이 0.45) 몸 위로 떨어지며 작아져 0.34초에 사라짐. 무작위 없이 항상 같은 모양. 앞 방향은 뒤 카메라에서 몸 위로 보이고, 옆 둘은 몸 밖으로 보임
4. 녹아 흐르는 슬라이드: 됨. 옆 1.5배·키 0.4배(0.32m)·앞뒤 1.5배. 앞(-z) 절반은 즉시, 뒤 절반은 스프링으로 따라와 시작할 때 몸 중심이 앞으로 쏠렸다 돌아옴. 끝날 때 앞이 먼저 모이고 뒤가 덜 모인 만큼 윗부분이 앞으로 기울어(drag 음수) 앞부터 솟은 뒤 위로 킥 + 출렁
5. 따라오기(시차): 됨. 셰이더 높이별 밀림에 위아래 sag 추가(레인 출렁임과 같은 스프링 세기·감쇠, 세기 0.3, 최대 0.05). 뛸 때 위가 조금 늦게 올라가고 착지 때 위가 늦게 내려앉았다 늦게 돌아옴. 슬라이드 중에는 꺼서 판정 높이를 넘지 않음
6. 예비 동작은 입력을 늦추지 않는 곳에서만: 됨. 입력 첫 프레임부터 늘어나며 뜸(자동 테스트). 팬케이크·반구·튕김 중 점프는 입력 프레임에 바로 뜨고 키 배율이 한 프레임에 0.2 이상 솟음(자동 테스트, 한 프레임 변화 0.45 이하라 툭 튀지 않음). 팬케이크 중 레인 이동도 입력 즉시(자동 테스트)
7. 충돌: v0.3.0 범위라 안 함
- 판정 값 그대로: 점프 0.6초·1.6, 슬라이드 0.65초·0.45배, 충돌 범위(자동 테스트 test_player_action)
- 슬라이드 중 보이는 몸 높이: 최대 0.32m + 표면 물결 < 0.36m(자동 테스트)
- 옆 레인과 겹침: 보이는 몸 폭 상한 1.55배(반폭 0.775, 테두리·표면 물결까지 약 0.82m) < 옆 레인 허들·막대 안쪽 끝 0.85m, 블록 0.95m(자동 테스트). 웹 PC 슬라이드 캡처에서 옆 레인 블록과 겹치지 않음

## 바꾸지 않은 것
