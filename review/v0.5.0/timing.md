# 박자 오차 (웹 빌드)

크로미움 헤드리스, Apple M3(Metal), 390x844, `--disable-audio-output`. 재현: `build_measure.sh` + `run_measure.sh`. 처음부터 130BPM을 지나 268초, 완벽한 자동 플레이어, 시드 143. 충돌 0, 오디오 시계 멈춤 0, 콘솔 오류 0.

- 프레임 기준: 도착이 보인 첫 프레임의 음악 시간 - 박 시각 (프레임 간격 16.7ms가 포함됨)
