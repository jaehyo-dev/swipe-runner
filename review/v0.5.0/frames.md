# 프레임 시간 (웹 빌드)

크로미움 헤드리스, Apple M3(Metal), 390x844, `--disable-audio-output`. 재현: `run_measure.sh`. 아이폰은 재지 못했다.

| 측정 | 프레임 | 중앙값 | 최대 | 33ms 초과 | 콘솔 오류 |
|---|---|---|---|---|---|
| 콜드 시작 15초 1회 (로딩 2.98초) | 900 | 16.7ms | 16.8ms | **0** | 0 |
| 콜드 시작 15초 2회 (로딩 1.49초) | 900 | 16.7ms | 16.8ms | **0** | 0 |
| 콜드 시작 15초 3회 (로딩 1.47초) | 900 | 16.7ms | 16.8ms | **0** | 0 |
| 처음부터 130BPM + 268초 | 16113 | 16.7ms | 16.8ms | **0** | 0 |
| 130BPM 시작 3분 | 10817 | 16.7ms | 16.8ms | **0** | 0 |

| 그리기 | v0.5.0 (130BPM 3분) | v0.4.1 (3분) |
|---|---|---|
| 그리는 횟수 평균 / 최대 | 44.2 / 59 | 28.8 / 39 |
| 삼각형 평균 / 최대 | 29,345 / 32,676 | 25,933 / 29,260 |

그리는 횟수가 평균 약 15회 늘었다. 장애물 하나가 면·선·반사 3회를 그리는데, 속도가 올라도 z -60까지의 줄 수는 비슷하지만 겹줄과 벽으로 줄당 장애물이 늘었기 때문이다. 하늘 돔 1회 증가.

새로 준비가 필요한 셰이더는 하늘 돔 하나이고 첫 화면 전 가림막 뒤에서 그려진다. 색 섞기는 재질 값만 바꾼다. 물방울 줄은 MultiMesh 값 48개를 프레임마다 바꾼다.
