# 소리 크기 측정 (음악 vs 효과음)

30초 녹화(Movie Maker)의 소리를 쟀다. 같은 장면을 음악만·효과음만 켜서 따로 녹음했고, 잰 함수는 후보 보고서와 같은 `a_weighted_db`.

| 소리 | 재생 횟수(겹치지 않은 것) | A 가중 크기 |
|---|---|---|
| lane | 3 | -32.8dB |
| jump | 3 | -31.2dB |
| slide | 4 | -31.4dB |
| land | 3 | -29.7dB |
| crash | 1 | -28.8dB |
| **lane·jump·slide 평균** | | **-31.8dB** |
| **음악** (첫 입력부터, 낮아진 1초 제외) | | **-34.3dB** |

**음악이 효과음보다 2.51dB 작다** (목표 2~3dB).

피크: 음악+효과음 전체 녹화 -4.04dBFS, 잘린 표본 0개.
참고: A 가중 없는 RMS는 음악 -15.8dB. A 가중은 저음을 크게 깎아, 저음이 많은 음악이 숫자보다 크게 느껴질 수 있다.

값 바꾸는 곳: `scripts/audio_manager.gd`의 `MUSIC_DB`, `SFX_DB`.
