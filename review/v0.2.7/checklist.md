## 조절 값
- `scripts/runner.gd` `AIR_WIDEST_T` = 0.49: 공중 가장 넓은 높이
- `AIR_LOWER_DEPTH` = 0.96(0.49 / 0.51): 아래 둥근 깊이 / 위 돔 높이. 몸 바닥이 y=0이라 위 값에서 자동으로 정해진다. 0.475 → 0.90, 0.49 → 0.96, 0.50 → 1.00
- 0.49보다 낮추면 위아래 시차가 최대일 때 0.9 아래로 내려가 자동 테스트가 실패한다(0.48 → 0.87)

## 바꾸지 않은 것
- 늘어남 크기(키 배율 두 버전 같음), 착지 팬케이크(키/폭·키 배율 같음), 판정 값, 색: 기존 자동 테스트 그대로 통과
- 그림자·물방울: 몸 바닥이 y=0에 그대로라 위치 계산을 바꿀 필요가 없음. 그림자는 몸 스케일과 높이만, 물방울은 고정 위치만 쓴다
